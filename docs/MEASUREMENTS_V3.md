# Фаза 0: Измерения и аудит стенда (v3.0)

**Дата замеров:** 2026-11-19  
**Стенд:** VOX UHD-65WSB684U (webOS 10.1.3, Linux 5.4.268 aarch64, Realtek RTD2875Q, `192.168.1.108`) $\leftrightarrow$ Яндекс Станция Мини 2 (Amlogic A113X ARMv7, ALSA 1.0.27, `192.168.1.132:5555`).
